# 關鍵指數小秘書：需求規格

每天把幾個指數的「5日線位置」和「KD 交叉」整理成報告，用 Telegram 送到手機。

## 1. 追蹤哪些指數（排序固定）

報告裡的「特別提醒」和「指數狀態」都照這個順序：

| 順序 | 指數 | 代號 |
|---|---|---|
| 1 | 費城半導體 | `^SOX` |
| 2 | 那斯達克綜合 | `^IXIC` |
| 2 | 那斯達克 100 | `^NDX`（和綜合放同一張卡） |
| 3 | 台灣加權 | `^TWII` |
| 4 | 櫃買指數 | FinMind `TPEx` |

資料來源：美股用 Yahoo Finance；台股用 FinMind，當天還沒更新時先用證交所即時資料補上收盤。

## 2. 什麼時候發

| 時間（台灣） | 內容 |
|---|---|
| 週二～週六 05:30 | 美股 + 台股（早報） |
| 週一～週五 13:35 | 只有台股（午報） |

- 排程用 GitHub Actions，設定在 [.github/workflows/daily-report.yml](../.github/workflows/daily-report.yml)。
- 資料還沒更新時，每 5 分鐘重試，最多等 60 分鐘；還是沒有就只送「今天沒有新資料」。

## 3. 判斷規則

| 項目 | 規則 |
|---|---|
| 5日線 | 最近 5 天收盤價的平均 |
| 突破 | 昨天收盤 ≤ 昨天 5日線，今天收盤 > 今天 5日線 |
| 跌破 | 昨天收盤 ≥ 昨天 5日線，今天收盤 < 今天 5日線 |
| KD | 日線 KD(9,3,3) |
| 黃金交叉 | 昨天 K ≤ D，今天 K > D |
| 死亡交叉 | 昨天 K ≥ D，今天 K < D |

## 4. 風險提醒

| 項目 | 狀態 | 什麼時候提醒 |
|---|---|---|
| VIX（Yahoo `^VIX`） | 已上線，只在早報 | 前一晚盤中最高 > 20，或收盤 ≥ 20（收盤在 20 以上就每天提醒）。不做半夜即時推播。抓不到時報告照送，這格顯示「抓不到」 |
| CNN 恐懼貪婪指數 | 暫停：CNN 會擋程式抓資料（HTTP 418），資料來源待定 | 昨天 ≥ 25、今天 < 25（從「恐慌」掉進「極度恐慌」） |

CNN 分級：0–24 極度恐慌、25–44 恐慌、45–55 中性、56–75 貪婪、76–100 極度貪婪。

## 5. 報告格式

- HTML 和文字版都要有，內容和順序一致。
- 版面以手機為主。公版：[template/daily_report_template.html](../template/daily_report_template.html)
- 顏色照台股習慣：紅 = 漲或轉強，綠 = 跌或轉弱。
- 用字要小學生也看得懂。

## 6. 通知管道

- 先做 Telegram bot（Telegram 機器人）：送文字版，最後附 HTML 報告的網址。
- HTML 放在 GitHub Pages（公開網頁）。
- 之後考慮加 LINE。
