# 關鍵指數小秘書：需求規格

每天把幾個指數的「5日線位置」和「KD 交叉」整理成報告，用 Telegram 送到手機。

## 1. 追蹤哪些指數（排序固定）

報告裡的「特別提醒」和「指數狀態」都照這個順序：

| 順序 | 指數 | 代號 |
|---|---|---|
| 1 | 費城半導體 | `^SOX` |
| 2 | 那斯達克綜合 | `^IXIC` |
| 2 | 那斯達克 100 | `^NDX`（和綜合放同一張卡） |
| 3 | 台灣加權 | `^TWII` |
| 4 | 櫃買指數 | FinMind `TPEx` |

資料來源：美股用 Yahoo Finance；台股用 FinMind，當天還沒更新時先用證交所即時資料補上收盤。

## 2. 什麼時候發

| 時間（台灣） | 內容 |
|---|---|
| 週二～週六 05:30 | 美股 + 台股（早報） |
| 週一～週五 13:35 | 只有台股（午報） |

- 排程用 GitHub Actions，設定在 [.github/workflows/daily-report.yml](../.github/workflows/daily-report.yml)。
- 資料還沒更新時，每 5 分鐘重試，最多等 60 分鐘；還是沒有就只送「今天沒有新資料」。

## 3. 判斷規則

| 項目 | 規則 |
|---|---|
| 5日線 | 最近 5 天收盤價的平均 |
| 突破 | 昨天收盤 ≤ 昨天 5日線，今天收盤 > 今天 5日線 |
| 跌破 | 昨天收盤 ≥ 昨天 5日線，今天收盤 < 今天 5日線 |
| KD | 日線 KD(9,3,3) |
| 黃金交叉 | 昨天 K ≤ D，今天 K > D |
| 死亡交叉 | 昨天 K ≥ D，今天 K < D |

## 4. 風險提醒

| 項目 | 狀態 | 什麼時候提醒 |
|---|---|---|
| VIX（Yahoo `^VIX`） | 已上線，只在早報 | 前一晚盤中最高 > 20，或收盤 ≥ 20（收盤在 20 以上就每天提醒）。不做半夜即時推播。抓不到時報告照送，這格顯示「抓不到」 |
| 仿 CNN 恐懼貪婪指數 | 已上線，只在早報。自己算的參考值，不是 CNN 官方數字。顯示今天和前一天，並附 [CNN 官方連結](https://edition.cnn.com/markets/fear-and-greed)。算不出來時報告照送 | **不自動提醒**。和 CNN 常差 10 分以上，用 25 當門檻會誤報。要不要擔心，點 CNN 連結自己看 |

CNN 分級：0–24 極度恐慌、25–44 恐慌、45–55 中性、56–75 貪婪、76–100 極度貪婪。

### 仿 CNN 恐懼貪婪指數怎麼算

**為什麼要自己算**：CNN 和財經M平方都會擋程式抓資料，M平方的服務條款也禁止下載數據。所以不抓網頁，改用 Yahoo 的公開行情自己算。

1. 先算 4 項指標（資料都來自 Yahoo，用含息調整後的收盤價）：

   | 指標 | 怎麼算 | 數字高代表 |
   |---|---|---|
   | 市場動能 | S&P 500（`^GSPC`）÷ 它的 125 日均線 | 貪婪 |
   | 市場波動 | VIX ÷ 它的 50 日均線，再加負號 | 貪婪（VIX 低） |
   | 避險需求 | 股票（`SPY`）20 天漲幅 − 中天期公債（`IEF`）20 天漲幅 | 貪婪 |
   | 垃圾債需求 | 高收益債（`HYG`）20 天漲幅 − 投資級公司債（`LQD`）20 天漲幅 | 貪婪 |

2. 每項指標都和自己過去 252 個交易日（約一年）比，算 z 分數（z-score，離平均有幾個標準差）。
3. 換成分數：50 + 15 × z，超出 0～100 就截在 0 或 100。
4. 4 個分數取平均，四捨五入成整數，就是指數。

**和 CNN 不一樣的地方**：CNN 用 7 項指標，另外 3 項（52 週新高新低家數、漲跌成交量、Put/Call 比）沒有免費資料，所以沒算。CNN 也沒公開它怎麼換算成 0～100。

**和 CNN 對過的數字**（2026/10/27 使用者截圖）：

| 時間點 | CNN | 我們 |
|---|---|---|
| 10/26 | 27 | 27 |
| 一週前 | 29 | 39 |
| 一個月前 | 36 | 56 |
| 一年前 | 37 | 52 |

平均差約 11 分，最多差 20 分。也試過用 S&P 500 的 500 檔成分股補算「新高新低家數」和「上漲成交量」，誤差沒有變小，每天還要多下載 20～30 秒，所以不用。重算方法：用上面 4 個日期，拿 `fetch_fear_greed` 同樣的公式算歷史值來比。

## 5. 報告格式

- HTML 和文字版都要有，內容和順序一致。
- 版面以手機為主。公版：[template/daily_report_template.html](../template/daily_report_template.html)
- 顏色照台股習慣：紅 = 漲或轉強，綠 = 跌或轉弱。
- 用字要小學生也看得懂。

## 6. 通知管道

- 先做 Telegram bot（Telegram 機器人）：送文字版，最後附 HTML 報告的網址。
- HTML 放在 GitHub Pages（公開網頁）。
- 之後考慮加 LINE。
